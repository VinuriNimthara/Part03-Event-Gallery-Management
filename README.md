# Part 03 – Event and Gallery Management

**Owns:** School events (with optional image) and the photo gallery album system.

## Files in this folder
- `admin/events.php` — Create/edit/delete events, optional event image upload.
- `teacher/events.php`, `student/events.php` — Read-only "Upcoming Events" views.
- `admin/gallery.php` — Create/edit/delete albums, upload cover photos, upload/delete photos inside an album.
- `teacher/gallery.php`, `student/gallery.php` — Read-only album browser.
